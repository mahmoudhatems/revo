- All sprites retain transparent backgrounds.
- Enlargement is 4x nearest-neighbor, not AI redraw or vector upscaling.
- The source image does not provide tile dimensions or a target in-game building footprint. These PNGs are enlarged source sprites, not yet normalized to a tile grid.
- Several functions are visually inferred from the building appearance. Confirm ambiguous station assignments against the current game scenario before wiring them into gameplay.
- The reference contains nine visible building/facility designs, not seven. The pack includes only those nine designs; it does not add Water & Recycling or Crew Health buildings unless visibly represented in the source.
